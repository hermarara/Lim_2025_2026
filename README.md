# Project Title Selection Structures
## Project Description
This is a simple Python program that tells you if a temperature is cold, safe or warm, based on the unit used.
## Features
- Enters the 3 units of temperature
- Calculates whether the temperature is hot, cold, or warm
- Handles invalid input (e.g., letters instead of numbers)

## How to Run the Program
1. Make sure you have Python installed.
2. Download the file `grade_calculator.py`.
3. Open a terminal or command prompt.
4. Run the program by pressing F5 or clicking 'Run' 
5. Follow the on-screen instructions to enter your unit and temperature.
